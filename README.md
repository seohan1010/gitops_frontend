# Frontend – React Application

## 📌 Overview
이 프로젝트는 **React.js 기반 프런트엔드 애플리케이션**입니다.  
백엔드 API와 연동하여 인증, 채팅, 공통 UI 레이아웃 기능을 제공합니다.

---

## 🛠 Tech Stack
- React.js
- JavaScript 
- npm
- Axios (HTTP Client)
- Zustand (State Management)
- CSS

---

## 📦 Prerequisites
- Node.js (npm 포함)

---

## 📥 Dependency Installation
프로젝트 실행 전, **의존성 설치가 필요합니다**.

npm install
