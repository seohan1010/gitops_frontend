# Frontend – React Application

## 📌 Overview
이 프로젝트는 **React.js 기반 프런트엔드 애플리케이션**입니다.  
백엔드 API와 연동하여 인증, 채팅, 공통 UI 레이아웃 기능을 제공합니다.

---

## 🛠 Tech Stack
- React.js
- JavaScript 
- npm
- Axios (HTTP Client)
- Zustand (State Management)
- CSS

---

## 📦 Prerequisites
- Node.js (npm 포함)

---

## 📥 Dependency Installation
프로젝트 실행 전, **의존성 설치가 필요합니다**.

npm install


## 📂 Project Structure
src/
├── auth/          # 인증 관련 컴포넌트
├── chat/          # 채팅 UI 및 로직
├── common/        # 공통 컴포넌트
├── header/        # 헤더 UI
├── menu/          # 메뉴 UI
├── store/         # Zustand 상태 관리
├── style/         # 전역 스타일
│
├── App.js
├── App.test.js
├── Request.js     # Axios 공통 요청 모듈
├── api.js         # API 설정
├── index.css
├── index.js
├── reportWebVitals.js
└── setupTests.js

## 프로젝트 실행 

npm start
